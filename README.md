## Maker 和 Taker 有什麼不同？

Maker 可以理解為「增加訂單簿流動性」的一方。你提交的委託沒有立即成交，而是留在訂單簿中等待其他人撮合，通常會按 Maker 費率計算。

Taker 則是直接吃掉訂單簿中已有委託的一方。市價單通常會立即成交，所以一般會使用 Taker 費率；限價單如果下單後馬上與現有委託成交，也可能被歸類為 Taker，而不是 Maker。

這裡有一個容易被誤解的地方：**Maker 和 Taker 不是單純按照「限價單」或「市價單」區分。**

| 下單方式 | 實際成交情況 | 常見費率類型 |
| --- | --- | --- |
| 市價單 | 直接與訂單簿已有委託成交 | Taker |
| 限價單 | 立即與已有委託成交 | Taker |
| 限價單 | 委託留在訂單簿，稍後由其他人撮合 | Maker |
| Post Only 限價單 | 強制只作為掛單成交，否則取消 | Maker |

如果你只是想快速買入 BTC、ETH 或其他幣種，市價單操作最直觀，但通常會承擔 Taker 費率以及可能的滑價。如果你不急著成交，可以使用限價單，並確認訂單確實留在訂單簿中。

OKX 也提供 Post Only 等進階委託類型，作用是避免訂單立即吃掉現有掛單。只是這種方式不保證一定成交，價格、深度和市場波動都會影響結果。

## OKX 現貨手續費怎麼計算？

現貨交易手續費的基本公式是：

text
交易手續費 = 適用費率 × 成交數量或成交金額


以普通用戶交易 BTC/USDT 為例：

### 市價買入 1,000 USDT 的 BTC

假設適用 Taker 費率 0.1000%，則：

text
1,000 USDT × 0.1000% = 1 USDT


實際收到的 BTC 數量會扣除對應手續費。OKX 的官方說明以買入現貨為例，手續費可能直接從買入的數字資產中扣除；賣出時，則可能從賣出所得中扣除。

### 限價賣出 1,000 USDT 的資產

如果這筆訂單以 Maker 費率 0.0800% 成交：

text
1,000 USDT × 0.0800% = 0.80 USDT


同樣的交易額，Maker 和 Taker 之間只差 0.20 USDT。單筆看起來不大，但如果你每天頻繁交易，或同一筆策略反覆進出，差距就會累積。

還要注意，交易手續費不是按照你「下單時看到的預估數字」永遠固定。不同成交批次、不同交易對或不同帳戶等級，可能適用不同費率。最可靠的做法，是在下單面板查看當前費率，成交後再到歷史委託或交易記錄確認實際扣款。

## 交易現貨時，還有哪些成本容易漏算？

查詢 OKX 現貨手續費時，很多人只計算 Maker 或 Taker，卻忽略了其他可能影響總成本的項目。

### 1. 買入和賣出會各自產生費用

你買入一次、賣出一次，通常就是兩次成交。不能只看買入時的 0.1%，然後把它當成整筆交易的完整成本。

### 2. 市價單可能有滑價

市價單會按照當時訂單簿中的可成交價格撮合。當市場波動大、深度不足或下單數量較大時，實際平均成交價可能和下單畫面看到的價格不同。

### 3. 不同幣對可能有不同費率組

OKX 並非所有現貨交易對都使用完全相同的費率。尤其是穩定幣、法幣、特殊活動交易對或特定市場，費率可能與標準組不同。官方費率頁面和下單面板才是確認依據。

### 4. 提幣費用不是現貨交易手續費

買賣現貨時支付的是交易費；將資產轉出平台時，則可能涉及網路和提幣費用。兩者不要混在一起比較。

### 5. 閃兌不等於現貨訂單簿交易

OKX 的 Convert 或閃兌功能可能展示「0 費率、無滑點」等產品說明，但它與現貨訂單簿的 Maker、Taker 費率不是同一套計算方式。要比較成本，應先確認你使用的是現貨交易、閃兌，還是其他產品。
